# سایار (Sayar)

نرم‌افزار موبایل‌محور حسابداری، فروش و مدیریت موجودی.

## وضعیت فعلی
نسخه 0.1.0 — پوسته اولیه داشبورد RTL و موبایل‌فرست.

## مسیر توسعه
- داشبورد مالی
- فروش و فاکتور
- خرید
- موجودی و گردش کالا
- اشخاص و حساب‌ها
- دریافت و پرداخت
- هزینه‌ها
- گزارش‌های بازه‌ای
- پشتیبان‌گیری و بازیابی
- آماده‌سازی PWA و سپس بسته‌بندی موبایل

## اصول داده
- ثبت تراکنش‌ها باید قابل ردیابی باشد.
- موجودی از روی گردش‌های ثبت‌شده محاسبه شود.
- مبلغ‌ها با دقت عددی مناسب حسابداری نگهداری شوند.
- تاریخ شمسی در رابط کاربری پشتیبانی شود.
- ساختار برای حالت آفلاین‌اول طراحی شود.

این پروژه مستقل از پروژه PsychGame است.\n\n## اشتراک ماهانه\n\nساختار اشتراک سایار از ابتدا به‌صورت **server-verified** طراحی شده است. اپلیکیشن وضعیت پرداخت را خودش معتبر نمی‌کند.\n\n- کلاینت برای ایجاد پرداخت به \`POST /subscription/checkout\` درخواست می‌فرستد.\n- سرور باید کاربر و مبلغ پلن ماهانه را تعیین کند و \`checkoutUrl\` برگرداند.\n- بعد از پرداخت، درگاه باید در سرور callback/verification شود.\n- وضعیت فعال اشتراک از \`GET /subscription/status\` خوانده می‌شود.\n- فقط وضعیت \`active\` اجازه ورود به امکانات اصلی برنامه را می‌دهد.\n- \`VITE_BILLING_API_URL\` آدرس سرویس اشتراک را مشخص می‌کند.\n\nدرگاه پرداخت واقعی در مرحله اتصال سرویس پرداخت انتخابی و بک‌اند احراز می‌شود؛ تا آن زمان هیچ پرداخت آزمایشی یا بازکردن جعلی امکانات در نسخه اصلی وجود ندارد.\n
